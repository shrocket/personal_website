I read this book on my phone. The file I have is a .mobi file, which is basically a deprecated file format when it comes to eBooks. So I had to find an eReader app that could deal with such files. Furthermore, the file I have was an imperfect OCR scan of a physical book and so maybe the scan was only >90% "correct," which meant I had to read around a lot of scanning errors, and so maybe I missed something important in book because I misinterpreted-- but that's always a danger, regardless of imperfect OCR scanning.

In any case, the book is a typical Dickian layering of realities extending past the boundaries of the physical book and into the reader's reality, so I feel as though the way I read it was appropriate.
