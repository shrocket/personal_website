Because there was a moment when. Because someone gave me an orange typewriter the other day. Because that caused me a certain amount of consternation. Because I want to be able to use it without consternation. Because it is orange. Because I need a massage. Because I also probably should go see the doctor. Because I mean the medical doctor. Because I can't see myself. Because the art at the Kunsthalle was not very good. Because the colors didn't match the form or the content. Because the pieces for which the artist is famous were, in fact, interesting. Because but there there only three of them. Because the rest of it had interesting elements, but was not, on the whole, particularly interesting. Because I tried to explain this in German today after helping to rub salve on a horse wearing a special outfit. Because the phrase "special outfit" sounds bizarre regardless of the context. Because the horse was wearing the special outfit, not me. Because living in Disneyland. Because I just thought bald men outside my window were saying my name. Because I think this has been done before and better by Tynes & Sikkema on the Facebook. Because really who cares if it's been done before. Because the sound of chains through plastic chairs twice a day. Because signs on umbrellas that say "do not push tables together." Because fresh raspberries off the bush both pre and post horse salve. Because the phrase "horse salve" sounds bizarre regardless of the context. Because I cannot move my neck and shoulders without some kind of pain. Because the nights are mild and tending toward cool even now in August. Because I am homesick for cicada sounds. Because I was so tired today. Because something needs to happen. Because I need to go somewhere. Because away. Because why. Because why not. Because fresh raspberries.
